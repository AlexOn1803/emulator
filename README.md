# ⚡ Симулятор Arduino / ESP8266 / ESP32

Браузерний симулятор мікроконтролерів з електронними компонентами. Пишете звичайний
Arduino-скетч, збираєте схему з резисторів, світлодіодів, моторів, датчиків — і
перевіряєте, як це працює, без жодного «заліза».

Працює повністю локально: **просто відкрийте `index.html` у браузері** (Chrome, Edge,
Firefox). Встановлювати нічого не потрібно, інтернет не потрібен.

## Можливості

**Плати**

| Плата | Логіка | Особливості |
|---|---|---|
| Arduino Uno | 5 В | `int` 16-бітний, ШІМ на 3/5/6/9/10/11, АЦП 10 біт (A0–A5), переривання на 2 і 3 |
| ESP8266 NodeMCU | 3.3 В | піни `D0…D8`, один аналоговий вхід `A0`, світлодіод на платі вмикається LOW, Wi‑Fi (імітація) |
| ESP32 DevKit V1 | 3.3 В | АЦП 12 біт, LEDC (`ledcAttach`, `ledcWrite`), ЦАП (`dacWrite`), піни 34–39 лише входи, Wi‑Fi (імітація) |

**Компоненти:** резистор (з кольоровим маркуванням), світлодіод (5 кольорів), RGB-світлодіод,
кнопка, перемикач, потенціометр, фоторезистор, діод (1N4007 / Шотткі), NPN-транзистор,
N‑MOSFET (IRLZ44N / IRF520), DC-моторчик, сервопривід SG90, п'єзозумер (активний/пасивний),
ультразвуковий датчик HC‑SR04, LCD 1602 з I2C, батарея, мультиметр (вольтметр/амперметр).

**Справжня електрика, а не «магія»:** схема розраховується методом вузлових потенціалів
(закон Ома, закони Кірхгофа). Світлодіоди та діоди мають падіння напруги, транзистор і
MOSFET працюють як ключі, ШІМ усереднюється правильно — тож яскравість і швидкість мотора
плавно змінюються від `analogWrite()`. Наведіть мишу на будь-який вивід, щоб побачити напругу.

**Підказки щодо типових помилок:**

- світлодіод без резистора — **перегорить** 💥;
- перевантаження піна (мотор напряму від піна, понад 40 мА на Uno / 12 мА на ESP8266);
- коротке замикання живлення;
- 5 В на вхід ESP (допустимо лише 3.3 В);
- кнопка без підтягувального резистора — «плаваючий» вхід читає випадкові значення;
- IRF520 від 3.3 В відкривається лише частково й гріється;
- серво, LCD чи HC‑SR04 без 5 В живлення, LCD з неправильною адресою чи пінами I2C;
- `digitalWrite` без `pinMode`, забутий `Serial.begin()`, ADC2 разом з Wi‑Fi на ESP32 тощо.

**Інструменти:** редактор коду з підсвіткою та автодоповненням (`Ctrl+Space`), монітор
порту з введенням, плоттер графіків, звук зумера, 23 готові приклади, збереження проєкту
у файл `.sim.json` та відкриття скетчів `.ino`, скасування змін схеми (`Ctrl+Z`).

## Як користуватися

1. Виберіть плату вгорі.
2. Клацніть на компонент у панелі ліворуч від схеми — він з'явиться на полотні.
3. З'єднайте виводи дротами: клацніть на вивід (кружечок), потім на інший вивід
   (або просто протягніть мишею). `Esc` / правий клік — скасувати.
4. Напишіть код ліворуч і натисніть **▶ Запуск** (`Ctrl+Enter`).
5. Під час роботи натискайте кнопки, крутіть потенціометр (тягніть ручку або коліщатко
   миші), змінюйте освітлення фоторезистора чи відстань для HC‑SR04.

Клавіші: `R` — повернути компонент, `Del` — видалити, `Ctrl+Z` / `Ctrl+Y` — скасувати/повторити.

## Підтримуваний код

Код перетворюється на JavaScript, тож підтримується найуживаніша частина C++:

- типи `int`, `long`, `byte`, `char`, `bool`, `float`, `double`, `String`, `uint8_t`… з
  правильним переповненням (наприклад, `int x = 40000;` на Uno дає `-25536`);
- масиви (зокрема багатовимірні), функції з параметрами за замовчуванням, `static`-змінні,
  `enum`, `#define` (зокрема з параметрами), `#ifdef ESP32 / #else / #endif`;
- `pinMode`, `digitalWrite/Read`, `analogWrite/Read`, `delay`, `millis`, `micros`, `map`,
  `constrain`, `random`, `tone/noTone`, `pulseIn`, `attachInterrupt`, математика, `bitRead`…;
- `Serial` (`print`, `println`, `printf`, `available`, `read`, `readStringUntil`, `parseInt`…),
  `String` і його методи, `sprintf`, `dtostrf`, `strcmp`, `strcpy`…;
- бібліотеки `Servo` / `ESP32Servo`, `LiquidCrystal_I2C`, `Wire`, `WiFi` / `ESP8266WiFi`
  (імітація підключення).

Не підтримуються: `struct`/`class`, вказівники, сторонні бібліотеки, справжня мережа.
Нескінченні цикли (`while(true){}`) безпечні — сторінка не зависає, а кнопка «Стоп» працює.

## Структура проєкту

```
index.html          інтерфейс
css/style.css       стилі
js/transpiler.js    Arduino C++ → JavaScript (з перевіркою помилок українською)
js/runtime.js       Arduino API, Serial, Servo, LCD, WiFi, ledc…
js/engine.js        розрахунок електричного кола (MNA)
js/components.js    компоненти: модель, малюнок, інтерактивність
js/boards.js        плати: піни, параметри, малюнок
js/schematic.js     редактор схеми (SVG)
js/examples.js      готові приклади
js/app.js           головний модуль інтерфейсу
vendor/codemirror   редактор коду CodeMirror 5 (MIT)
test/               тести
```

## Як додати свій компонент

Опишіть об'єкт у `js/components.js`: виводи (`pins`), властивості (`props`), електричну
модель (`stamp` — додає провідності та джерела в матрицю, `update` — для нелінійних
елементів, `measure` — обчислює струми), анімацію (`animate`, `refresh`) і малюнок (`svg`).
Додайте тип у `Sim.componentOrder` та іконку в `Sim.componentIcons`.
